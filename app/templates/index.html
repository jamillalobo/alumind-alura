Bem-vindo ao AluMind Analyzer!

Este é um sistema para análise de feedbacks de usuários, com foco em bem-estar e saúde mental.

Rotas disponíveis:

  • Enviar novo feedback: POST /feedbacks Content-Type: application/json { "id": "4042f20a-45f4-4647-8050-139ac16f610b", "feedback": "Gosto muito de usar o Alumind! Está me ajudando bastante em relação a alguns problemas que tenho. Só quer ia que houvesse uma forma mais fácil de eu mesmo realizar a edição do meu perfil dentro da minha conta" }
  • Ver relatório de feedbacks: /report
  • Ver detalhes de um feedback: /report/feedback/<id>
  • Enviar resumo semanal por e-mail: POST /send_mail

Use essas rotas para interagir com a API e visualizar relatórios detalhados.
